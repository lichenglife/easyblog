## 说明

## 模块一：用户系统

### US-U1: 用户注册
| 属性 | 描述 |
|------|------|
| **ID** | US-U1 |
| **优先级** | P0 |
| **故事** | 作为**访客**，我想要**通过用户名 + 密码注册账号**，以便**成为系统用户** |
| **验收标准** | • 用户名唯一性校验（4-30 位字母数字下划线）<br>• 密码强度校验（6-30 位）<br>• 邮箱格式校验<br>• 注册成功后状态为"待审核"<br>• 待审核状态无法登录 |

### US-U2: 用户名密码登录
| 属性 | 描述 |
|------|------|
| **ID** | US-U2 |
| **优先级** | P0 |
| **故事** | 作为**注册用户**，我想要**通过用户名密码登录**，以便**访问个人功能** |
| **验收标准** | • 审核通过的用户才能登录<br>• 密码错误返回友好提示<br>• 登录成功返回 JWT Token（有效期 2 小时）<br>• Token 包含用户 ID 和角色信息 |

### US-U3: GitHub 第三方登录
| 属性 | 描述 |
|------|------|
| **ID** | US-U3 |
| **优先级** | P1 |
| **故事** | 作为**访客**，我想要**使用 GitHub 账号登录**，以便**无需记住密码** |
| **验收标准** | • 实现 GitHub OAuth 2.0 授权流程<br>• 首次登录需绑定已有系统账号<br>• 绑定后可通过 GitHub 直接登录<br>• 解绑后需重新绑定 |

### US-U4: 记住我/自动登录
| 属性 | 描述 |
|------|------|
| **ID** | US-U4 |
| **优先级** | P2 |
| **故事** | 作为**注册用户**，我想要**登录后保持状态**，以便**无需频繁登录** |
| **验收标准** | • 支持"记住我"选项<br>• 记住我有效期 7 天<br>• Token 过期自动刷新<br>• 登出后清除记住状态 |

### US-U5: 修改个人信息
| 属性 | 描述 |
|------|------|
| **ID** | US-U5 |
| **优先级** | P1 |
| **故事** | 作为**注册用户**，我想要**修改昵称/邮箱/手机**，以便**更新个人信息** |
| **验收标准** | • 昵称：2-30 字符，唯一性检查<br>• 邮箱：格式校验，唯一性检查<br>• 手机：格式校验，唯一性检查<br>• 修改后立即生效 |

### US-U6: 修改密码
| 属性 | 描述 |
|------|------|
| **ID** | US-U6 |
| **优先级** | P1 |
| **故事** | 作为**注册用户**，我想要**修改密码**，以便**保障账号安全** |
| **验收标准** | • 需验证当前密码<br>• 新密码强度校验（6-30 位）<br>• 密码使用 bcrypt 加密存储<br>• 修改成功后所有设备需重新登录 |

### US-U7: 用户登出
| 属性 | 描述 |
|------|------|
| **ID** | US-U7 |
| **优先级** | P1 |
| **故事** | 作为**注册用户**，我想要**安全登出**，以便**保护账号安全** |
| **验收标准** | • 登出后 Token 失效<br>• 清除本地会话<br>• 返回登出成功响应 |
