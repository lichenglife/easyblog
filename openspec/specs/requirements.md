# 博客系统需求规范

**状态**: 已确认  
**创建时间**: 2026-04-01  
**最后更新**: 2026-04-01

---

## 一、系统定位

本系统为博客管理系统，用于公司内部员工用于发布技术、生活博客，记录学习主题、生活工作故事。

---

## 二、用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 游客 | 未登录访问者 | 浏览文章 |
| 注册用户 | 已认证用户 | 创作、管理内容 |
| 管理员 | 系统管理者 | 内容审核、用户管理 |

---

## 三、功能需求

### 3.1 用户模块

**基础功能：**
- [ ] 注册（用户名 + 密码）
- [ ] 登录/登出
- [ ] 修改个人信息
- [ ] 修改密码
- [ ] JWT 认证

**增强功能：**
- [ ] GitHub 第三方登录
- [ ] 邮箱验证
- [ ] 找回密码
- [ ] 记住我/自动登录

### 3.2 内容模块

**基础功能：**
- [ ] 创建文章
- [ ] 编辑文章
- [ ] 删除文章
- [ ] 查看文章
- [ ] 文章列表
- [ ] 分页
- [ ] 搜索

**增强功能：**
- [ ] Markdown 编辑器
- [ ] 封面图
- [ ] 文章置顶
- [ ] 图片上传功能
- [ ] 标签/分类

### 3.3 互动模块

- [ ] 评论系统
- [ ] 点赞功能

### 3.4 管理模块

**管理方式：** 集成式管理（非独立后台），管理员登录后显示管理功能

**初始管理员：**
- 账号：`admin`
- 密码：`admin123`

**功能：**
- [ ] 用户管理（封禁、删除、角色分配）
- [ ] 文章管理（编辑、删除、置顶、审核）
- [ ] 评论管理（删除、审核）
- [ ] 系统配置（站点名称、公告等）

---

## 四、非功能需求

### 4.1 性能
- API 响应时间 < 200ms

### 4.2 安全
- 密码加密存储（bcrypt）
- JWT Token 认证
- 接口权限校验

### 4.3 可扩展性
- 支持后续功能扩展

### 4.4 文档
- 需要 Swagger/OpenAPI 文档

---

## 五、技术约束

- 语言：Go 1.23.5+
- 数据库：MySQL
- 缓存：Redis
- Web 框架：Gin
- 图片存储：本地 (/data 目录) + 远端对象存储 双存储
- 文档：Swagger/OpenAPI

## 六、已决策事项

### 用户系统决策
1. **注册审核**：需要管理员审核（注册后等待批准才能登录）
   - 待审核状态用户无法登录
   - 审核拒绝需填写理由
   - 审核通知：站内信
2. **GitHub 登录**：首次需绑定已有账号
3. **密码找回**：暂不需要

### 内容系统决策
4. **文章状态**：不需要草稿功能
5. **文章删除**：硬删除，关联评论一起删除
6. **分类结构**：多级树状分类（最多 3 级）
   - 有下级分类或文章时不可删除
   - 需从下逐层删除
7. **标签数量**：限制每篇文章最多 5 个标签

### 评论系统决策
8. **评论审核**：无需审核，发布即显示
9. **评论编辑**：支持无限次编辑，标记"已编辑"
10. **楼中楼层级**：限制最多 3 层

### 图片存储决策
11. **存储方式**：本地 (/data 目录) + 远端对象存储 双存储
    - 以本地存储为准
    - 对象存储为备份
    - 存储失败降级为本地保存与读取
12. **图片大小**：不限制
13. **图片处理**：原图存储

### 权限决策
14. **置顶权限**：仅管理员可置顶
15. **删除评论**：评论作者 + 文章作者 + 管理员
