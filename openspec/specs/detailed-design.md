### 9.2 数据库索引

```sql

-- 文章表索引

CREATE INDEX idx_post_id ON comment(post_id);
CREATE INDEX idx_root_id ON comment(root_id, floor);

-- 点赞表索引
CREATE UNIQUE INDEX uk_user_target ON like(user_id, target_type, target_id);
```
