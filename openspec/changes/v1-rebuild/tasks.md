## 测试要求

### 后端测试覆盖率要求

| 模块 | 覆盖率要求 |
|------|----------|
| Handler 层 | ≥ 80% |
| Biz 层 | ≥ 80% |
| Store 层 | ≥ 80% |
| Model 层 | ≥ 70% |
| Middleware | ≥ 80% |
| 工具函数 | ≥ 90% |

### 前端测试要求

| 类型 | 工具 | 要求 |
|------|------|------|
| 组件测试 | Vitest | 核心组件覆盖率≥80% |
| E2E 测试 | Playwright | 核心流程 100% 覆盖 |

### 测试规范

**后端**
1. 测试文件命名：`xxx_test.go`
2. 测试函数命名：`TestXxx_Function_Scenario`
3. 表驱动测试：多个场景使用表驱动测试
4. Mock 依赖：使用 go-sqlmock/mocks 隔离外部依赖
5. 测试数据：使用测试工厂创建测试数据

**前端**
1. 测试文件命名：`xxx.test.tsx`
2. 组件测试使用 @testing-library/vue
3. E2E 测试使用 Playwright
4. Mock API 使用 MSW

### 测试分类

| 类型 | 位置 | 说明 |
|------|------|------|
| 单元测试（后端） | `internal/xxx/xxx_test.go` | 测试单个函数/方法 |
| 单元测试（前端） | `src/xxx/__tests__/xxx.test.tsx` | 测试组件/函数 |
| 集成测试 | `tests/integration/` | 测试 API 接口 |
| E2E 测试 | `tests/e2e/` | 端到端测试 |
| 性能测试 | `tests/benchmark/` | 性能基准测试 |
